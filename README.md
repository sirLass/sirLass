* 🎯 Savings goal tracking
* 📅 Dynamic financial reports
* 📊 Interactive data visualization

### 🤖 NU-Lipa FAQ Chatbot

An offline AI-powered FAQ chatbot built for **National University–Lipa**, grounded in the school's own knowledge base.

The system combines:

* 🧠 Multitask BERT
* 🔎 Semantic search with FAISS
* 🏷️ Entity extraction
* 💬 Context-aware conversations
* 🎯 Confidence-based retrieval
* 🛡️ Rule-based response validation

**Built with:** Python, PyTorch, Hugging Face Transformers, Sentence Transformers, FAISS, Rasa, scikit-learn, Pandas

🔗 [View Repository](https://github.com/Zendevve/faq-chatbot)
